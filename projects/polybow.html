Polybow

A trading experiment and its postmortem: how the signal and execution path changed, and why faster responses did not establish a durable edge.

Python · WebSockets · APIs · AWS Lightsail

Try Polybow ↗Read the code ↗

The problem

A short-lived disagreement between BTC direction and an outcome contract was only useful if the quote was real, enough shares were available and the order arrived in time.

My contribution

I worked on the signal and execution experiments and the later analysis. The public repository contains the case study, ledger calculations and a timing parser, not the private trading bot. It is an engineering investigation, not a deployable strategy.

Try it step by step

  1. Read the Polybow, StratA, StratB and UC branches and the problem each change addressed.
  2. Follow the execution section: book events, warm connections, metadata preparation and order submission.
  3. Read the timing definition before interpreting the numbers. An API response is not a confirmed fill.
  4. Expand Inspect the trading record and compare the market ledger with the separately explained wallet cash result.
  5. Use the public CSV and analysis script to reproduce the ledger calculation. Private input logs are needed to reproduce the archived timing statistics.

Implementation, step by step

  1. Define the signal hypothesis and record the inputs used by each branch.
  2. Move evaluation to book events and reduce avoidable preparation work.
  3. Measure a specifically defined timing window rather than comparing unrelated intervals.
  4. Reconcile outcomes and retain losses, uncertainty and differences between accounting methods.
  5. Publish the reproducible ledger analysis and label what cannot be independently reproduced from the public repository.

Limits and unfinished work

The experiment did not establish durable profitability. Dublin was not evaluated with a controlled regional comparison. The public CSV is market-resolution accounting, not the wallet cash balance. Private bot code and raw latency logs are not included.
